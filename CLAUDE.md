# Dealectric — context for Claude Code sessions

Read this before judging project status from the repo alone. Much of the operational state lives outside git.

## What this repo is
- Static site for https://dealectric.com (GitHub Pages, `main` branch, `/docs` folder, extensionless pages). Only `docs/` is published; everything else in the repo (this file, `TODO.md`, `launch-status.md`, `src/`) is not served on dealectric.com, though the repo itself is public on GitHub.
- Generator in `src/`: `build.py` (pages, offers.json, sitemap), `content.py` (prose), `products.py` (31 product records, `VERIFIED` date), `links.json` (CJ/Awin program IDs + link IDs). `python3 src/build.py` regenerates everything and writes the published site to `docs/` (it replaces the folder, so never hand-edit files there).
- Open items: the "Dealectric To-Dos" artifact (https://claude.ai/artifact/8eV4jpzzYbQVtotF5EmAkp, IDs `DLC-<n>`) is the source of truth; see "Project to-do lists" in the global CLAUDE.md. Current status detail: `launch-status.md`; `TODO.md` is an older mirror. Trust these over any inference from the code. Both are mirrored to the Claude project ("Agent Discoverable") as `ops/TODO.md` and `ops/launch-status.md`.

## State that is NOT visible in this repo (don't report it as missing)
- **Traffic tracking is live** via Cloudflare (account barrryyao@gmail.com, zone dealectric.com, proxy on). Web Analytics is injected at the edge, so there is intentionally no analytics `<script>` in the HTML. Request/visitor/AI-crawler reports: Cloudflare dashboard → dealectric.com → Analytics and AI Crawl Control.
- **Search indexing is set up**: Google Search Console (sc-domain:dealectric.com, verified by DNS TXT, sitemap submitted 2026-10-14) and Bing Webmaster Tools (verified by DNS CNAME, sitemap submitted 2026-10-14).
- **Affiliate program statuses** (approved / declined / pending) live in the CJ and Awin dashboards and in `launch-status.md`, not in code. `links.json` only lists approved programs with links in use.
- Awin payouts are blocked until the account owner enables two-step verification and enters bank details (owner action, not code).

- **The edge Worker is live** (`worker/`, Cloudflare Worker `dealectric-edge`, deployed 2026-10-18): `/go/<slug>` logs the click to D1 and 302s to the CJ/Awin link with sub-ID `<slug>.<clickid>`; `/feedback` (GET or POST) stores agent/human feedback in D1. Every offer link on the site and in offers.json is now `https://dealectric.com/go/<slug>`; `worker/src/links-map.json` is generated by `build.py`, so rebuild before `npx wrangler deploy` when products change. Deploy token: keychain item `cloudflare-workers-token`. Read the data with `wrangler d1 execute dealectric --remote --command ...` (see `worker/README.md`). Nothing of this is visible in GitHub Pages.
- `python3` on this machine may be 3.11 (Anaconda); the generator needs 3.12: `python3.12 src/build.py`.
