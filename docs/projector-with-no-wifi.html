Why a Google TV projector needs the internet once

Google TV offers an offline setup called basic TV, with no Google account and no internet. Google's help page says basic TV can play media from inputs plugged into the device and use a limited set of pre-installed apps. It can't install apps, open the Play Library or receive a cast from another device. You can only choose it during first setup. Once full Google TV is set up, you need a factory reset to switch. Google describes basic TV as a feature of TVs with Google TV built in, so check your projector's setup screen.

USB playback is a separate catch. Nebula's support page for its Google TV projectors says: "Before using a USB flash drive, you must install a file manager," because "Google's policy prohibits pre-installing file managers on the system." Nebula recommends VLC, MX Player or Kodi to play the files. FAT32 and NTFS drives are fully supported; on exFAT drives, only MX Player plays files. Even Nebula's "play videos without Wi-Fi" guide for the Capsule 3 Laser has you install File Explorer from the Google Play Store as its second step. It supports drives up to 4 TB.

The practical fix is to connect once, for example through a phone hotspot. Complete the full Google TV setup, install a file manager and a player, then use the projector offline. If the projector will never see a network, pick one with no smart system, such as the Epson, or a router-free link, such as the Aurzen ZIP projectors. The ZIP Pro's USB-C video input needs a source whose USB-C port supports DisplayPort Alt Mode. Aurzen says budget and older phones rarely do. Aurzen also says Netflix, Hulu and Disney+ content can't be mirrored to the ZIP, so bring your own video files.

Not recommended

If you have no Wi-Fi, skip the ViewSonic LX60HD. It is built around Google TV and built-in Wi-Fi. Offline it is an HDMI, USB and AV-input projector that runs only on AC power, and installing apps or casting to it needs the full, signed-in Google TV setup. Its rated 630 ANSI lumens is 630 ÷ 2,061 ≈ 31% of the Epson's measured output.
