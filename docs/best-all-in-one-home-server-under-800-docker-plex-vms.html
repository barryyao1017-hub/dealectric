What the workload needs

  • Home Assistant OS as a VM: 2 GB RAM and 2 vCPUs minimum, UEFI boot, a bridged network adapter (Home Assistant's install page).
  • Windows 11 as a VM: 4 GB RAM, 2 virtual processors, 64 GB disk, UEFI with Secure Boot and a vTPM 2.0 (Microsoft's requirements page); UGREEN's guest tools cover Windows 7, 10 and 11.
  • Plex: hardware transcoding needs a Plex Pass and an Intel CPU with Quick Sync; without it Plex wants about 2,000 PassMark per 1080p stream and 12,000–17,000 for 4K, which none of these CPUs spare while VMs run.
  • Adding up: 2 GB (HAOS) + 4 GB (Windows) + 2–4 GB of containers + Plex + UGOS itself is 10–12 GB, so 16 GB is comfortable and 32 GB roomy; the DXP4800 Plus takes up to 64 GB in two slots.
  • Storage: put the Docker volumes and VM disks on an M.2 SSD pool and the media on the hard drives; UGOS runs the VM app only on the DXP series, not the DH series.

UGOS Pro's VM app

UGREEN's own guide and support article describe a Virtual Machine app on DXP models with VM snapshots (take one before risky changes), ISO import from the NAS or an upload, OVA import and export, bridged networking, guest tools for Windows, and guests including Windows, Linux, OpenWRT and iKuai; a USB device can be assigned to one VM at a time. UGREEN names no hypervisor and publishes no per-VM vCPU or RAM ceiling, and a reviewer's discrete-GPU passthrough test failed in a Windows VM, so treat GPU and iGPU passthrough as unavailable. Reviewers (TechPowerUp, ITPro) call the Plus capable for most home uses but not a machine for many VMs; for that, Proxmox on the same hardware is the usual route.
