Measured battery life and brightness: what a keyboard workload gets

Once a tablet sits in a keyboard cover, it spends hours with the screen on, browsing and editing documents. Notebookcheck runs the same Wi-Fi browsing script and measures maximum brightness with a colorimeter on every tablet it tests, so these figures compare directly:

The two FE models ran longest. The S11 and S11 Ultra have the brightest screens but ran shorter. MyNextTablet's own battery test put the S10 FE at 8.5 h and the S11 at 12.75 h, the opposite order. Its test script differs from Notebookcheck's, so compare each lab's figures only with that lab's other results.

The 12.7-inch Lenovo Idea Tab Pro is the dim one: 409 ÷ 667 = 61% of the S10 FE's measured brightness. It has two strengths: Notebookcheck confirms wired output to an external monitor using the DisplayPort standard, and its keyboard dock attaches by pogo pins. The Idea Tab Pro Gen 2 fixes the brightness at 618 cd/m².

The S10 FE and S10 FE+ keyboards attach by pogo pins (Samsung UK and Germany spec pages), so there is no Bluetooth pairing or keyboard battery to charge. Samsung US now also titles the S11 Ultra keyboards for a Galaxy Tab S12 Ultra, so check that newer model before paying Ultra prices.

Not recommended

Galaxy Tab S11 as a laptop replacement. Samsung sells only the Book Cover Keyboard Slim for it, with no trackpad option, so you need a separate mouse to use DeX like a laptop. It also had the shortest Wi-Fi runtime Notebookcheck measured here (11 h 14 min), and with its keyboard it costs $1,144.98. As a light tablet for typing only it works well. For keyboard-first use, the S10 FE kit costs $395.00 less, has a trackpad and runs 3 h 33 min longer.
