Why execution units decide Intel transcoding for Plex

Every CPU in this group lists Intel Quick Sync Video as supported, so every one can hardware-decode and encode for Plex. Plex Pass is required for this on any of them, as QNAP's Plex page states. The boxes differ in the GPU wrapped around the media engine. Intel ARK lists 80 execution units on the i5-1235U and 24 on both TVS-h674 chips, the i5-12400 and i3-12100. The QNAP's desktop CPU is faster at general computing but carries the smaller graphics block.

The size of that block matters most for HDR tone mapping, which converts a 4K HDR file for an SDR screen. Jellyfin's Intel hardware-acceleration guide describes two ways to do it. One is QSV VPP, which runs on 'Intel fixed-function LUT hardware' and works only on some GPU models. The other is OpenCL, which runs as GPU compute work. The guide notes that low-power encoding 'can offload the GPU usage' and so helps 'speeding up the OpenCL based HDR/DV tone-mapping'. In other words, tone mapping shares the GPU with everything else the GPU is doing. Execution units are that GPU's compute array, so more of them leave more room for that shared work. No named reviewer has published a measured count of simultaneous Plex 4K streams for any of these boxes. Read the 80-vs-24 gap as headroom, not as a stream count.

One fix for the DXP6800 Pro's memory. Intel's footnote for the i5-1235U says the Iris Xe brand applies only when 'the system must be populated with 128-bit (dual channel) memory. Otherwise, use the Intel UHD brand.' IT Pro reports that the DXP6800 Pro 'comes with one 8GB stick'. Quick Sync works as shipped. To get the dual-channel configuration Intel rates as Iris Xe, add a matching DDR5 SO-DIMM. We found no named measurement of how much single-channel memory slows Plex on this unit.

Not recommended

QNAP TS-664 with a dual-port 10GbE card. QNAP lists the dual-port QXG-10G2T as an option for the TS-664. However, the box's only slot is PCIe Gen 3 x2, about 15.8 Gb/s, which is less than two 10GbE links need. Its N5095 also has the smallest GPU in this group at 16 EU. If you want 10GbE and 4K Plex on a budget, the DXP6800 Pro gives both ports and five times the execution units.
