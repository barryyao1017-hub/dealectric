Why a combo doesn't buy you a better scan-to-print workflow

In these combos the scanner and the printer never connect to each other. Creality's own CR-Scan Otter guide describes the steps: plug the scanner into a computer's USB 3.0 port and scan in CrealityScan. Then export the model as STL and open it in the Creality Print slicer, which sends it to the printer. For that scanner the computer needs Windows 10/11 64-bit (at least an 8th-gen Intel i5 with 8 GB RAM, 16 GB recommended) or macOS 10.15.7 or later. Any printer that accepts an STL file fits these steps, so the box adds nothing technically. What it adds is a discount, and on today's prices that discount is $169.80–$389.00. The 'Save' labels look bigger because they're measured against compare-at prices. For example, the K1 Max + Raptor's $2,298 compare-at is $870 above the $1,428 the two parts cost on their own today.
