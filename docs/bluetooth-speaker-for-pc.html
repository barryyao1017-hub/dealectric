  • Pebble X Plus, PC port vs adapter: 30 W RMS ÷ 15 W RMS = 2×.

Why a Bluetooth speaker with a mic goes mono on a PC

Windows plays music to a Bluetooth speaker over A2DP, the stereo profile. On Windows 11, a speaker that also supports the Hands-Free Profile (HFP) gets a microphone input. Microsoft's driver documentation says Windows switches the speaker to HFP when any app opens that input or starts a playback stream in the Communications category. HFP is mono, at 8 kHz (narrowband, SBC) or 16 kHz (wideband, mSBC), and Windows resamples everything else that is playing to match. Windows 10 is worse: while the speaker is in hands-free mode, "any audio streaming to the stereo output is discarded."

There are three ways around it:

  • Buy a speaker with no hands-free profile. Creative lists only A2DP for the Pebble Pro and the Pebble X Plus. Microsoft says an A2DP-only device gets an output and no input, so call apps have to use the webcam, headset or desk mic, and the speakers keep playing in stereo.
  • Use the wired input. USB-C audio (Pebble Pro, Pebble X Plus, Pebble V3, T60, M60), micro-USB (Z407) or 3.5 mm skips Bluetooth profiles entirely.
  • Keep the speaker off the mic list. The Creative T60 lists HFP. Over Bluetooth, set Windows' default microphone and each call app's mic to another device, or play to the T60 over USB-C.

On a PC, the codec matters less than the profile. Microsoft's list of Windows codecs is aptX Adaptive (Windows 11 24H2, only on select Qualcomm radios), AAC (Windows 11 only), aptX Classic and SBC. LDAC is not on it. Edifier specifies the M60's LDAC for Android 8.0 or later, so from a Windows PC the M60 falls back to SBC. The Pebble Pro, Pebble X Plus and T60 list SBC only; Creative's Pebble V3 page names no codec. Bluetooth LE Audio came to Windows 11 in version 22H2. Microsoft says its LC3 codec has to come from the PC's audio driver or Bluetooth controller, so an LE Audio-ready speaker only gets LE Audio on PCs built for it.

Not recommended

The Marshall Emberton III as a PC speaker for calls. Marshall builds in a microphone for hands-free calling. That is exactly the setup Windows switches to mono 8 or 16 kHz when Teams or Discord opens a mic. Marshall lists no wired audio input (the USB-C cable is for charging), so there is no cable to fall back on. It suits a phone and a bag, not a desk PC that takes calls.
