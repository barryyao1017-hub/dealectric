What happens to the fans after you install Unraid or TrueNAS

A NAS maker's own OS drives the fan chip directly. Replace that OS and fan control depends on whether the new OS has a driver for the chip: an ITE it87-family chip on UGREEN, an ITE8528 embedded controller on QNAP, or an IT8625E on Asustor. Some boards instead keep a BIOS fan setting that works under any OS.

UGREEN on Unraid: the community UGREEN NAS Control plugin runs on Unraid 7.2+ without a kernel module, so Unraid updates don't break it. The plugin lists the DXP6800 Pro and DXP4800 GT as verified and the DXP4800 Plus as community-tested. On 2026-11-07 a DXP4800 Plus owner confirmed that fans, LEDs, the case view and the beeper all work on Unraid 7.3.4 with plugin 5.5.0. The maintainer recorded the report. The one gap is that a press on the power button isn't registered.

UGREEN on TrueNAS: TrueNAS doesn't ship a driver that can read or set the fan. Oscar Molnar compiled the it87 module from groeck/it87 in a Debian container and loaded it with insmod. With the stock auto fan, his drives ran at 37–41 °C during a backup and the box measured 41 dB at idle. The UGREEN-Fan-Control project warns that the module must be built for the exact kernel release it loads on. It lists the DXP6800 Pro as only partially supported.

Disable the UGREEN watchdog first: UGREEN's BIOS watchdog reboots the NAS every 3 minutes if UGOS isn't running, per NASCompares. Connect a monitor and keyboard, open the BIOS (NASCompares says to press F12 and Delete repeatedly at power-on, or Ctrl+F12) and turn off the watchdog under Advanced, or under FAST on i5 models. Do it quickly, before the timer reboots the box. Once Unraid is installed, the plugin's README says to keep the BIOS watchdog armed: the plugin feeds it, so only a frozen box reboots.

TerraMaster F4-424 Pro: Notebookcheck notes that the fan is adjustable in the BIOS. It ran at 875 rpm and measured 33.7 dB at idle in their test. Because it's a BIOS setting, the same speed applies under Unraid or TrueNAS. TerraMaster's newer F4-425 Pro (Intel N350, 16 GB, dual 5GbE) boots Unraid 7 from a rear USB port, according to an owner's install guide. That guide doesn't cover the fan, so the F4-425 Pro stays out of the table until owners publish fan results.

QNAP TS-464: on Unraid, ich777's QNAP-EC plugin (updated 2026-11-06) loads the embedded-controller module and can write fan PWM values. On TrueNAS, the request to bundle the qnap8528 driver was closed as not accepted. The workaround given in that thread is to run the fans at 100%.

For an Unraid build, the $619.99: https://dealectric.com/go/ugreen-nasync-dxp4800-plus has the best-documented fan support of the boxes under $700. If you need six bays, the $1,099.99: https://dealectric.com/go/ugreen-nasync-dxp6800-pro is the plugin's other verified model.

Not recommended

Asustor Lockerstor 4 Gen2 (AS6704T) for TrueNAS. On TrueNAS SCALE 25.x its IT8625E fan chip stays at a fixed 20% PWM whatever the CPU or disk temperature (forum user sakej, 2026-06-10). The power button does nothing, and the disk LEDs stay static, so a degraded pool looks the same as a healthy one. Full fan control needs a DKMS module and TrueNAS developer mode, and iXsystems turns away support requests from systems running that way.
