What the differences mean

Each box here can be reached from a phone behind CGNAT through its maker's relay. Two things separate them: how fast the relay is once it carries the traffic, and whether the NAS can also run Tailscale, which usually finds a direct path.

  • QNAP relay, 1 GB of phone video: 8,000 Mb ÷ 2 Mbps = 4,000 s ≈ 67 min; at 1 Mbps, 8,000 s ≈ 133 min.
  • Tailscale's own DERP relay test (Delhi to Minnesota, 2.2 Mbps): 8,000 Mb ÷ 2.2 ≈ 3,636 s ≈ 61 min. Over its peer relay at 27.5 Mbps: 8,000 ÷ 27.5 ≈ 291 s ≈ 4.8 min.
  • DXP2800 over DH2300: $389.99 − $239.99 = $150 on UGREEN's store (2026-11-17). For this job, the extra money buys Docker, which is how UGREEN runs Tailscale.

Which NAS can run Tailscale, and why it matters behind CGNAT

David Anderson of Tailscale calls CGNAT "a run of the mill double-NAT" that is "mostly okay" for a direct connection, adding that "the big thing that breaks is our port mapping protocols." QuickConnect's automatic UPnP rules and any DDNS setup depend on port mapping, so behind Starlink or 5G home internet the maker apps fall back to their relay servers. Tailscale tries a direct path first and treats its DERP relay as the "fallback of last resort".

  • UGREEN DXP2800: Tailscale runs as a Docker container, which is UGREEN's supported method. Android Central's Harish Jonnalagadda found "you can install just about any service via Docker, and it runs well."
  • UGREEN DH2300: UGREEN states it "does not support Docker and cannot use this method", so UGREENlink is its only route.
  • Synology DS225+ and DS223j: Tailscale says the Package Center copy "is no longer supported". Install Tailscale's DSM 7 .spk by hand instead (x86_64 and armv8 builds, version 1.104.7 on 2026-11-17). By default it accepts only inbound connections, which is the direction a phone needs.
  • QNAP TS-264-8G: Tailscale is in App Center under Communications, for x86-64 and arm-64 devices.
  • Asustor AS5402T: Tailscale is a community Docker package in App Central (AS54 listed, ADM 5.0.0 or later). The listing says it "is not officially supported by Tailscale Inc."

Not recommended

The UGREEN NASync DH2300 is the wrong box if you plan to pull video or run large phone backups away from home. It is the cheapest box here at $239.99, but it has no Docker, so it cannot run Tailscale and every remote byte goes over UGREENlink. For opening files and single photos it works.
