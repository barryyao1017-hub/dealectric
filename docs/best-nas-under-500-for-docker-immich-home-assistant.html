What Immich and Home Assistant need

  • Immich: 6 GB RAM minimum, 8 GB recommended, 2 cores minimum and 4 recommended; its machine-learning container needs an x86-64-v2 CPU (the N100 qualifies) and can be disabled in Administration → Machine Learning Settings or moved to another Docker host with the remote-ML guide (smart search and face detection go remote; facial recognition stays local). With 4 GB, run it with ML off.
  • Home Assistant: the Container install runs anywhere Docker does but has no add-ons; Home Assistant OS, which has them, needs a VM with 2 GB RAM, 2 vCPUs, UEFI and a bridged network adapter. UGREEN's DXP models run it as a VM per owner guides; one DXP2800 owner reported the VM getting no IP address, with no clear fix in the thread.
  • Zigbee and Z-Wave sticks must be passed through to the container or VM by hand on every platform.

Why the DXP2800

Under $500 the choice is between x86 boxes with 4 GB (Asustor, Synology, TerraMaster F2-425) that need a RAM upgrade before Immich's machine learning runs comfortably, ARM boxes (UGREEN DH2300, Asustor Drivestor) that cannot run x86 containers or VMs, and two N100/N150 units that ship with 8 GB: the DXP2800 and TerraMaster's F2-425 Plus. The TerraMaster has the newer chip, 5GbE and a 32 GB ceiling; the UGREEN has a verified price, HDMI out, a documented VM path and two years' warranty. If 5GbE matters, price the TerraMaster on the day. The Beelink ME mini is the cheapest N150 box but has no drive bays and no NAS software.

Running both at once

Immich with ML on uses most of 8 GB during imports; Home Assistant OS takes 2 GB more. On the DXP2800, fit a 16 GB SO-DIMM (its ceiling) and put the Docker pool on an M.2 SSD so the photo library's database and thumbnails are not on spinning disks. UGOS's Docker app reserves nothing on 9443, but one guide warns against publishing Portainer there.
