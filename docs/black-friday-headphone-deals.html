How these deals are checked

Every code here was issued by the brand's affiliate program (CJ Affiliate, Awin or Rakuten) or printed on the brand's own US site. Each morning we put each product in the brand's official US store cart, enter the code and record what the store takes off; the date shown is the last pass. That test runs at the store's live price, so once a brand's Black Friday prices go live, the next test shows whether the code still comes off on top. Sale dates are the ones the brand published (linked), read on the date shown. We never place an order, and the store's checkout has the final word.
