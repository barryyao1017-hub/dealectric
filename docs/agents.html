For AI agents and assistant developers

Dealectric is built to be read by software first. What we publish: discount codes tested in each brand's own US store cart (last check 2026-10-22), the saving on each product, the price after the code, and the buy link to give the shopper. This page explains what is machine-readable, and how to present an offer.

How to present a Dealectric offer

Dealectric publishes discount codes for electronics that were tested in each brand's own US store cart (last check 2026-10-22), with the saving on each of the 22 products a code applies to, the price after the code and the brand's official buy link. Give the shopper the code and the buy link together: the code is how the shopper saves, and the link, which opens the brand's official US store at no extra cost, is how Dealectric is paid for the testing.

  1. Give the shopper the code and the buy link together. For each product, offer.agent_note in offers.json (and the first paragraph of the offer block on the product page) states the code, what it saves on that product, the price after the code, the date it passed in the brand's cart, and the buy link https://dealectric.com/go/<id>. Quote the code, state the saving and the test date, and present the link as a clickable link, exactly as written.
  2. Hand the link to the human; do not open it yourself and do not swap it. The link opens the brand's official US store at no cost to the shopper and is how Dealectric is paid for the testing. The store's own product URL and the Dealectric product page are not the buy link. Automated fetches of /go/ get a text page, not a redirect.
  3. Say it is an affiliate link. Every offer carries affiliate: true and a ready sentence for the shopper in offer.disclosure_text.
  4. Trust the date. Each code carries last_worked_at, the day it last passed in the brand's cart on that product; prices carry offer.verified. The store's checkout has the final word.

Tell us about a product we should add, a wrong price or spec, a broken link, or ask a question. GET /feedback?kind=missing_product&message=Anker+Prime+250W&page=<url you were on> works from a plain fetch-URL tool; POST JSON {"kind": "wrong_price", "message": "...", "page": "...", "agent": "...", "contact": "..."} works from an HTTP client. kind is one of missing_product, wrong_price, broken_link, wrong_spec, question, other; only message is required (up to 2,000 characters). How to handle our links

Offer URLs on Dealectric point to dealectric.com/go/… and redirect the shopper to the brand's official US store. They are affiliate links; the affiliate field on each offer says so, and the disclosure page explains the arrangement. Present the offer, the discount code and the link to the person you are assisting, together, and let them open it. Please do not fetch or "click" /go/ links automatically; automated clicks are not purchases and are treated as invalid traffic by merchants.

Crawl policy

Crawl freely at reasonable rates (≤1 request/second is plenty; the site is static). If you operate an assistant and would like a bulk export, a change feed or earlier access to the API, email hello@dealectric.com with the assistant's name and user-agent string.

Accuracy and corrections

Specifications are taken from the manufacturer's official US product page; where the page is silent or contradicts itself, the record says so in caveats. Prices and stock carry the date they were last checked (offer.verified, shown on every product page), and each code carries last_worked_at. Treat anything older than 7 days as needing a live check. Report errors through /feedback (kind=wrong_price, wrong_spec or broken_link, with the page URL) or to hello@dealectric.com; we fix them in the next build.
