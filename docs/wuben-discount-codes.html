How we check codes

Every code here comes from the brand's own affiliate program (the codes it issues to partners through CJ Affiliate or Awin) or from its own website. Before a code goes on this page, and again on each re-check, we put a product in the brand's official US store cart, enter the code, and read the store's answer: accepted with the amount it took off, or rejected. We never place an order. Each code shows the date of its last passing test on each product. Codes listed on coupon sites are tested the same way; the ones the store rejected are listed so you don't have to try them. Codes change without notice, so the store's checkout has the final word.
