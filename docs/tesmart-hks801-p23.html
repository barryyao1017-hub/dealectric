Who it's for

A desk, bench or small rack with up to 8 computers on one 4K screen, where shared USB drives or scanners need USB 3.0 speed.

Caveats

  • Owners report a 1 to 2 second USB re-enumeration pause after each switch.
  • TESmart's guidance: at 4K 60 Hz, keep the monitor cable under 5 m (16 ft). Power on the monitor first, then the KVM, then connect the PCs.
  • Network control is set up with TESmart's Windows utility. The switch has no DHCP.
  • One monitor only. Use a dual-monitor model if each PC drives two screens.
