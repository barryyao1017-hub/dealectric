What Paperless-ngx needs

  • The stack: the official compose file runs the webserver (ghcr.io/paperless-ngx/paperless-ngx), Redis as the broker, PostgreSQL (recommended for new installs; SQLite for the smallest boxes), and optionally Gotenberg and Tika for Office files. The image is published for amd64 and arm64.
  • CPU and RAM: no published minimum; OCR (OCRmyPDF/Tesseract) uses every core by default, with one task worker and threads set to the core count. The docs' advice for small boxes is SQLite, one webserver worker, OCR mode auto (skip pages that already carry text) and OCR clean none. An N100 with 8 GB runs it with headroom; extra OCR languages cost CPU.
  • Consume folder: Paperless watches it, imports each file and deletes it. Scanners reach it over an SMB or FTP share on the NAS; if the folder sits on a network mount from elsewhere, set the polling interval because inotify does not fire. Email consumption (mail rules, every 10 minutes) and the mobile apps are the other inputs. Set USERMAP_UID/GID to a user that can write the folder.
  • Backups: document_exporter writes originals, archive PDFs, thumbnails and a manifest.json of the database, runs incrementally and imports only into the same Paperless version; schedule it to a second disk and keep an off-site copy. RAID 1 protects against a dead drive, not a deletion.
  • Version churn: Paperless 3.x renamed settings and requires the database engine to be set explicitly, so third-party guides go stale; start from the project's compose file.

Scanners that feed the consume folder without a PC

  • Brother ADS-4300N (about $400–530): scan to SMB network folder, FTP or SFTP from the panel.
  • Brother ADS-1800W (replaces the discontinued ADS-1700W, $249.99): network folder (CIFS) and FTP.
  • Ricoh ScanSnap iX1600 (about $400–460): one of only two ScanSnaps (with the iX2500) that save straight to a NAS folder, over SMB 1.0–3.0.2, but direct save drops searchable-PDF, naming and deskew; let Paperless do the OCR.
  • Epson ES-580W (about $380–450): SMB, FTP, email and cloud destinations.

Use a dedicated scanner account with write access to the consume folder only; SMB version mismatches and paths are the usual failures.

Storage math

A 300-dpi black-and-white page is about 50–200 KB, a colour page 1–3 MB, so 10,000 pages is roughly 0.5–2 GB in black and white or 10–30 GB in colour, and Paperless roughly doubles that with its OCR'd archive copy (which you can turn off). Two 4 TB drives in RAID 1 hold decades of paper; the budget goes into the box, the scanner and the backup, not the disks.
