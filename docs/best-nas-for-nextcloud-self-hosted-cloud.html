Why per-core speed and the Docker version decide a Nextcloud NAS

Nextcloud is a PHP web app. Every page you open, every photo preview and every file the sync client checks is a separate request, and one PHP process works through each request on one core. A faster core therefore answers sooner, and more cores let more requests run at the same time. PassMark's single-thread rating measures that one-core speed. The scores are PassMark's averages of user-submitted runs on each chip, not runs on the NAS itself, and the V1500B average rests on only 14 samples, against 4,173 for the N100.

The second gate is Docker. Nextcloud All-in-One (AIO), which Nextcloud calls its official install method, sends every Docker request at API v1.44 unless you override it, and its readme says only the default API version is supported and tested. Docker's own version table gives Engine 24.0 a maximum API of 1.43 and Engine 25.0 a maximum of 1.44. Marius Hosting's October 2026 cross-brand table lists Synology at Engine 24.0.2, QNAP at 27.1.2, TerraMaster at 27.2.1 and UGREEN at 29.6.2. That makes Synology's Container Manager the only one below AIO's default. On the DS925+ and DS225+, the readme's DSM steps have you run AIO over SSH or a root scheduled task, mount Synology's own socket path and adjust the API version. One DSM owner reported AppAPI failing in a loop at 1.43 (AIO issue #7365). It can be done, but not in a setup the AIO maintainers test.

Synology also restricts upgrades. Its DS925+ spec page says M.2 storage pools need Synology-verified SSDs and that Synology won't give full warranty or support if you add non-Synology memory. Its own 16 GB module (D4ES03-16G) is listed at $1,184.99 as a special order at Central Computer.

Power measured at the wall (each reviewer used different drives, so compare loosely): KitGuru, DXP4800 Plus, 24.25 W idle on 2.5GbE with WD Red drives. NAS Compares, DS925+, about 28 W idle. Notebookcheck, F4-424 Pro, 23.8 W idle with two hard drives and one SSD. Club386, TS-464, 19 W with drives spun down. igor'sLAB, DXP2800, 14.5 W during transfers with one NVMe SSD and no hard drives.

Not recommended

Synology DS225+: it has the lowest CPU Mark here (2,927), ships with 2 GB and tops out at 6 GB, has no M.2 slots for the database (Racks & Watts), and runs the same Docker Engine 24.0.2 as the DS925+. UGREEN NASync DH2300: UGREEN's FAQ says it “does not officially support Docker”. AIO installs only through Docker, so the DH2300 can't run it. The 2-bay UGREEN to buy for Nextcloud is the DXP2800.
