What the differences mean

  • Detector headroom on the pick's CPU: at 12 ms per detection, one OpenVINO detector can run about 83 inferences a second (1000 ÷ 12). That is the Pentium Gold 8505 figure from discussion #11960.
  • The same report's load: five 1080p cameras detecting at 5 fps each is 25 frames a second (5 × 5), and the CPU sat at about 50%. With detection switched off, the user saw 5–10%.
  • N100 in the 2-bay box: about 15 ms per detection works out to about 67 inferences a second (1000 ÷ 15). Frigate's table also says the N100 runs only one detector instance, so all cameras share that one detector.
  • Cores for other containers: the F4-425 Pro's N350 has 8 cores, against the 8505's 5 (1 performance + 4 efficiency). That is 3 more cores (8 − 5) for Home Assistant or other Docker services next to Frigate.
  • Memory ceiling: the DS225+ ships with 2 GB and tops out at 6 GB (2 + 4). The DXP4800 Plus ships with 8 GB, and Intel lists a 64 GB maximum for its CPU, eight times the shipped amount (64 ÷ 8).

The AVX check: which NAS CPUs can run Frigate 0.17

Frigate's developer FAQ for 0.17 says: "Frigate 0.17 requires a modern CPU with AVX (Advanced Vector Extensions) instructions." A startup crash with an illegal instruction error has the listed cause "Your CPU lacks AVX instructions required by TensorFlow". Frigate's hardware page sets the bar higher: "Anything with an Intel CPU (with AVX + AVX2 instructions) and capable of running Debian should work fine."

The specs printed on a NAS box don't answer this. The QNAP TS-464 has a Celeron N5095 with Intel UHD Graphics and Quick Sync, yet Intel's spec page lists its only instruction-set extension as SSE4.2. The Celeron N5105 in the Asustor AS5402T and the Celeron J4125 in the Synology DS225+ and DS425+ have the same SSE4.2-only listing. The Pentium Gold 8505 (DXP4800 Plus), N100 (DXP2800) and Core 3 N350 (F4-425 Pro) all list AVX2.

To check any NAS yourself, open Intel's spec page for its CPU and read the "Instruction Set Extensions" line. On a box you already have shell access to, run grep -o -w avx2 /proc/cpuinfo | head -1. If it prints nothing, the CPU has no AVX2. If you run Frigate inside a Proxmox VM on a CPU that does have AVX, the FAQ's fix for the crash is to set the VM's CPU type to "host" so the instructions pass through.

Detection on Celerons has a second problem. A Frigate maintainer wrote in discussion #13388 that "Celeron is not officially supported for openvino". That thread covers OpenVINO GPU-detector failures on J4125 and J5005 systems.

Not recommended

QNAP TS-464 for running Frigate. It looks like a good fit: Intel x86, UHD graphics, 4 bays, 8 GB. But Intel lists its N5095 with SSE4.2 only, which is below the AVX line in Frigate's 0.17 FAQ, and a Frigate maintainer says OpenVINO isn't officially supported on Celeron. The Synology DS225+ and Asustor AS5402T have the same problem. The DS225+ also ships with only 2 GB of RAM. These units can still hold recordings as storage, but the official Frigate image should run on an AVX2 machine.
