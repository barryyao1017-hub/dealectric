Frigate's own requirements

  • CPU: AVX and AVX2 are required; Intel Celeron and Pentium parts before Tiger Lake typically lack them, but the Alder Lake Pentium Gold 8505 and the N100 have them.
  • RAM: 4 GB for a few cameras, 8 GB with face or licence-plate enrichments, 16 GB recommended for most users and for 8+ cameras.
  • Detectors: the CPU detector is "not recommended for general use"; OpenVINO runs on 6th-gen Intel and newer iGPUs (N100 and N150 about 15 ms per inference, one detector instance; UHD 730 about 10 ms); the Coral USB needs no host driver but is "no longer recommended for new installations" and does not throttle itself; M.2 or mini-PCIe Coral and Hailo-8/8L (about 7–11 ms) need host kernel drivers, so on a NAS they only work where you control the kernel (Proxmox, Unraid, TrueNAS).
  • Video decode: preset-vaapi on 8th–12th-gen Intel (QSV optional), preset-intel-qsv on 13th-gen and newer; there is no CPU fallback if hardware decode fails.
  • Docker: map /dev/dri/renderD128 for the iGPU, /dev/bus/usb for a Coral USB, set shm_size from Frigate's formula (about 210 MB for two 720p cameras; the example uses 512 MB), and privileged mode "may not be necessary".
  • Storage: surveillance-rated hard drives (WD Purple, Seagate SkyHawk) for 24/7 recording; SSD wear worries are "largely no longer valid"; Frigate's emergency cleanup starts below about an hour of free space.

Frigate on each NAS OS

UGOS: a Docker Compose project with the devices mapped; a May 2026 guide describes it with QSV and warns UGOS updates can reset bind mounts, but no owner has published a working Frigate report, only an Immich-with-iGPU one, so treat it as the expected route rather than a proven one. Synology: enable "Execute container using high privilege" (tested on DSM 7.1.1); a DS718+ owner runs a Coral USB on DSM 7.2. QNAP: Container Station cannot pull from GitHub's registry or change the 64 MB shm, so install from the command line. TrueNAS SCALE: one owner reports preset-vaapi failing on 25.10 with a Coral USB working without hardware decode. Home Assistant OS: no Intel NPU or GPU support, shared memory about half of RAM.

Storage math

A 1080p H.265 camera at 2–4 Mbps writes about 0.9–1.8 GB an hour: 0.65–1.3 TB per camera per 30 days of continuous recording, so four cameras need roughly 2.6–5.2 TB a month and 4K roughly three times that; Frigate's default motion-only recording cuts it well below. Two 8 TB surveillance drives in RAID 1 hold a month of four 1080p cameras with margin; prices for WD Purple Pro 8 TB were about $400 and IronWolf Pro 8 TB about $220–275 in 2026 listings, undated.
