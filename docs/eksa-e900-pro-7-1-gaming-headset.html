Caveats

  • The boom mic is fine for chat, not for streaming or recording; no headset mic matches a desk dynamic mic.
  • Reviewers find the 3.5 mm mode sounds flatter than the USB mode; use USB on PC.
  • 7.1 virtual surround only works through the USB cable on PC with the software installed.
