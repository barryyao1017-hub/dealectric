Data schema

Every product on Dealectric is described with a shared core record plus a category-specific field set, all in the same units, and every offer carries provenance. Pages embed this as schema.org/Product and schema.org/Offer JSON-LD; a JSON API with the same shape is planned (see For AI agents).

Product record (core + charging/power fields, the launch category)

FieldType / unitNotes
idstringStable slug, e.g. anker-prime-100w-3-port
brand, model, skustringManufacturer model number as printed on the product
categoryenumLaunch set: wall_charger · power_bank · cable · wireless_charger · power_station · surge_protector. Planned: security_camera, smart_plug, router, earbuds, headphones, speaker, robot_vacuum, air_purifier, and more — each with its own field block
max_output_winteger, WTotal headline output
ports[]arrayEach: type (usb_c / usb_a / ac / dc12 / wireless), max_w, protocols[] (pd3.0, pd3.1_epr, pps, qc3, qc4+, …)
power_distribution[]arrayPer-combination split, e.g. {"ports":["c1","c2"],"w":[65,30]}
capacity_wh, capacity_mahnumberPower banks / stations; Wh is canonical
chemistryenumlfp · nmc · li_ion · unknown
cycle_lifeintegerManufacturer-rated cycles to 80%
ac_continuous_w, ac_surge_winteger, WPower stations
rechargeobjectac_max_w, solar_max_w, solar_voltage_range, ups_switchover_ms
cableobjectrated_w (60/100/240), emarker (bool), data_gbps, length_m, usb_if_certified
airline_carry_onenumok (≤100 Wh) · approval_required (101–160 Wh) · not_allowed
dimensions_mm, weight_gnumbers
safety_certs[]arrayul, etl, ce, ukca, fcc, psE…
warranty_monthsinteger
source_urls[], spec_verified_atarray, ISO dateWhere the specs came from and when we last checked

Offer record

FieldType / unitNotes
product_idstring
merchantstringWho fulfils the order (brand store, authorized retailer)
price, currencynumber, ISO 4217List price at verification
coupons[]arrayEvery code that applies to one unit, biggest saving first. Each: code, type (percent/fixed), value, terms, min_order, min_qty, expires, last_worked_at (date the code last worked in the brand's own cart), tested_on (product it was tested on), saving, source. coupon / coupon_terms repeat the best one. Codes with conditions and the codes that failed are on codes_page.
effective_pricenumberPrice after the best code in coupons
shippingobjectfree_over, regions[], est_days
return_window_daysinteger
in_stockbool
urlURLA dealectric.com link that redirects to the merchant. This may be an affiliate link — see affiliate.
affiliateboolTrue when we earn a commission on purchases through url
verified_atISO datetimeWhen price and stock were last checked

Illustrative record with a fictional brand. Units: W, Wh, mm, g. Dates are UTC ISO 8601.

Category field blocks (planned)

Non-power categories reuse the core record and add their own block. Examples of the fields each will carry: earbuds/headphones — driver size, codecs (AAC, LDAC, aptX), ANC (yes/no, adaptive), battery hours with and without case, multipoint, IP rating; security cameras — resolution, field of view, local vs cloud storage, subscription required, PoE/battery/wired, night-vision type, ecosystem (HomeKit, Alexa, Google); routers — Wi-Fi generation, bands, max link rate, ports, mesh support; robot vacuums — suction (Pa), mop type, self-empty/self-wash dock, mapping (LiDAR/vSLAM), runtime; small kitchen appliances — wattage, capacity, footprint, dishwasher-safe parts. Field names and units will be published here before each category goes live.
