Premiere and Resolve rules

  • Resolve: the project database lives on the workstation (a shared database needs the PostgreSQL Project Server and Resolve Studio); the render cache goes to the first Media Storage volume you set, so set a local SSD first. Media on an SMB share is how vendors and Blackmagic forum staff describe the normal setup, though Blackmagic publishes no SMB guarantee.
  • Premiere: Adobe's community staff call a network media cache unsupported; keep it on a local NVMe separate from the footage. Footage on the NAS is fine over a fast link; for laptops, Ingest with proxies (Media Encoder) or Attach Proxies for proxies made elsewhere.
  • macOS SMB: Apple's nsmb.conf documentation covers protocol versions and the port only; the common "signing_required=no" tweak is community advice with mixed results and lowers LAN security.

Thunderbolt on these NAS units

UGREEN's Thunderbolt 4 ports form a point-to-point network link to one computer, not a mounted drive; owners report about 2 GB/s reads on a Mac from the DXP480T Plus and reviewers 10–20 Gb/s to PCs. QNAP's TB4 NAS measured 1,850–1,930 MB/s on a Mac in StorageReview's test, so expect the same class. A Mac on 10GbE needs a Thunderbolt adapter (Sonnet Solo10G about $193–224, OWC about $160–200, QNAP QNA-T310G1T about $199) or the direct Thunderbolt cable, which needs no switch at all; several editors sharing the NAS need a 10GbE switch (QNAP QSW-2104-2T about $200–215).
