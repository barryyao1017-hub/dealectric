What a Minecraft server needs

  • RAM (Java): minecraft.wiki's server page lists 1 GB for 1–4 players, 2 GB for 5–10 and 4 GB for more, about 50–100 MB per player; PaperMC's Aikar's-flags guide is more generous, recommending 6–10 GB for the Java heap and leaving 1–1.5 GB for the OS, and calls 32 GB wasted. Mods and modpacks sit at the top of those ranges.
  • CPU: "good single-core performance"; the server uses about three cores at most and hyperthreading adds little. The N100's 3.4 GHz and the Pentium Gold 8505's 4.4 GHz are the relevant numbers here, not the core counts.
  • Java and disk: Java 21 from Minecraft 1.20.5; worlds start at a few hundred megabytes and grow with exploration. Bedrock's dedicated server lists an i3-3210-class CPU and 4 GB on Mojang's page, with community guides running small worlds in 1–2 GB.

The Docker route on UGOS

In UGOS's Docker app create a Project and paste a compose file for itzg/minecraft-server: EULA set to TRUE, VERSION pinned, MEMORY (the Java heap, 1G by default; 2G–4G for friends) with a container limit about 25% above it, USE_AIKAR_FLAGS for Paper, a ./data volume for the world, port 25565 TCP (19132 UDP for the separate itzg/minecraft-bedrock-server image, or GeyserMC and Floodgate to let Bedrock players join a Java server). The UGREEN owner guide used host networking; a port mapping is the alternative. Backups are the data folder: snapshot or copy it on a schedule.

Letting friends in

Forward port 25565 on the router to the NAS and give friends a DDNS name, or run a playit.gg tunnel container next to the server, which needs no open ports (community images exist; clients may fail to ping the server list entry but can connect). Tailscale works too for friends who install it. Keep the server whitelisted either way.

What owners report

A July 2025 guide on a DXP2800 (N100, 8 GB, 2.5GbE) calls it "not high-performance but competent", advises about ten users at moderate view and simulation distance and warns off large or complex servers; a mini-PC guide reports 19–20 TPS with 8–10 players on an N100 with 16 GB, dipping to 17–18 during chunk generation. No one has published a DXP4800 Plus test; its higher clock and RAM ceiling are the reason to choose it for a bigger or modded server, not a measured result. A Raspberry Pi 5 is estimated at 4–6 players at a steady 20 TPS.
