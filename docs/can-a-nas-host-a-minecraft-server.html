What the differences mean

All five run Docker on x86, so all five can run a Minecraft Java server container. What separates them is how fast one core is, because that core runs the server's world tick. Single-thread figures are PassMark's averages for each CPU as of 8 November 2026. They are not measured inside these NAS units.

  • DXP4800 Plus vs DXP2800: 3,197 / 1,879 = 1.70× the single-thread speed for $230 more ($619.99 − $389.99 at UGREEN's US store, 2026-11-08).
  • DXP4800 Plus vs QNAP TS-464: 3,197 / 1,492 = 2.14×.
  • DXP4800 Plus vs Synology DS925+: 3,197 / 1,136 = 2.81×. PassMark's V1500B figure rests on 14 samples, so treat it as approximate.
  • The budget pick still beats the 4-bay rivals: the DXP2800's N100 rates 1,879 / 1,492 = 1.26× the TS-464's N5095 and 1,879 / 1,136 = 1.65× the DS925+'s V1500B.
  • Speed per dollar: DXP4800 Plus 3,197 / 619.99 = 5.2 points per dollar; DXP2800 1,879 / 389.99 = 4.8. The faster box doesn't cost more per point.
  • Synology's two models are level: DS925+ 1,136 vs DS225+ 1,151, a 1% gap. The 4-bay Synology is no faster a game host than the 2-bay one.
  • Memory headroom: the DS225+ tops out at 6 GB in total (2 GB + 4 GB in one slot), shared by DSM and every container. The DXP4800 Plus ships with 8 GB DDR5 and takes up to 64 GB (KitGuru).

One fast core decides it, and the DXP4800 Plus has exactly one

PaperMC's Folia README describes standard Paper as single-threaded: "the current Paper (single threaded) can be viewed as one giant 'region' that encompasses all chunks in all worlds." Folia, the multithreaded fork, asks for at least 16 cores and a large player count, so it doesn't suit a home NAS. A friends-sized server lives or dies on one core.

That is also why the "4.4 GHz" in UGREEN's listing needs a footnote. Intel's spec sheet for the Pentium Gold 8505 lists 1 performance core at up to 4.40 GHz and 4 efficient cores at up to 3.30 GHz. Only one core reaches the advertised clock, and PassMark's single-thread test, which runs one thread, scores that fast core at 3,197. We have not seen a published test of which core UGOS gives a container's main thread. Even on an E-core, the ceiling is 3.3 GHz, above the TS-464's 2.9 GHz and the DS925+'s 2.2 GHz.

Core count and clock claims mislead in both directions:

  • More cores: Intel's 8-core i3-N305 has a slightly higher PassMark CPU Mark than the 8505 (9,337 vs 8,997, +3.8%), but its single-thread rating is 2,032. The 8505 is 3,197 / 2,032 = 1.57× faster on the thread Minecraft uses.
  • Higher turbo: Intel's N150 is sold as "up to 3.6 GHz" against the N100's 3.4 GHz, yet PassMark rates them 1,889 vs 1,879, a 0.5% gap.
  • No turbo at all: the DS925+'s Ryzen V1500B runs at 2.2 GHz with no boost. That is why a 4-bay Synology rates lowest here.

If any friend plays Bedrock

GeyserMC says that from Bedrock 26.60 (27 October 2026) Bedrock clients stopped connecting over RakNet, the transport that old "forward UDP 19132" guides were written for. Bedrock players now join over Mojang's NetherNet. On any of these x86 boxes, two setups work:

  • Java server plus Geyser (build 1237 or later, NetherNet enabled): forward 19132 on both TCP and UDP, because NetherNet needs a TCP port for signaling. In Docker, GeyserMC points to -DgeyserAdvertiseAddresses for servers "in containers or behind a NAT".
  • Bedrock Dedicated Server (itzg/minecraft-bedrock-server image): TCP 19132 for signaling, plus a UDP range set in SERVER_UDP_PORTS with at least one port per player. The README says "BDS does not listen on UDP port 19132". With the default max-players of 10, that means TCP 19132 plus 10 UDP ports.

With either setup, keep the NAS admin page off the internet and forward only the game ports. $619.99; buy: https://dealectric.com/go/ugreen-nasync-dxp4800-plus
