Plex's own rules

  • Plex Pass: hardware-accelerated streaming is a premium feature; tone mapping needs a Plex Pass on the server owner's account too (a lifetime pass was about $250 in 2026).
  • CPU generations: Plex's hardware-transcoding article recommends 5th-gen Core or newer, needs 7th-gen for HEVC encoding, and says NAS units need "a Jasper Lake or better CPU for reliable HEVC output". The N100 and N150 are newer than Jasper Lake; the J4125 (Gemini Lake Refresh) is older.
  • Tone mapping (HDR to SDR): hardware tone mapping on Linux, Docker and NAS needs Plex Media Server 1.29.2 or newer and an Intel Kaby Lake or newer iGPU; Windows needs Tiger Lake or newer, and macOS has no hardware option. Jasper Lake and Alder Lake-N both qualify; Gemini Lake does not.
  • Docker: hardware transcoding in a container needs the kernel's render device bound into the container (Plex calls it an advanced setup); UGREEN's Docker app exposes that through its compose "projects".

How many streams

No lab has published a tone-mapped 4K stream count for these boxes. Owner reports for the N100 under Linux range from two 4K HDR tone-mapped transcodes (including 60 fps remuxes) while a library scan ran, to three or four 4K HDR-to-1080p streams; a Windows test held five mixed 1080p/HEVC transcodes at about 35% CPU but Windows has no hardware tone mapping. Jasper Lake (N5095, N5105) shares the same Quick Sync block as the N100's predecessor and should behave alike; the J4125 is reported unable to transcode 4K reliably in real time. Treat all of it as a range, not a specification.

What changed at Synology

Synology's 2025 two-bay Plus models (DS225+, DS425+) use the same J4125 as the DS224+, but owners and NASCompares report the i915 graphics driver is gone from DSM and Synology support calls hardware transcoding unsupported on them; a community patch restores it with root access. DSM 7.3 (October 2025) let the 2025 Plus, Value and J models create pools on third-party hard drives again, but M.2 pools still need Synology-verified SSDs.
