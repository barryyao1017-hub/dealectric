Who it's for

Small shops that want pro-tier laser line counts and the tightest claimed accuracy under $1,000 and already own a recent gaming-class PC.

Caveats

  • Same body, weight and marker needs as the MetroX; the gains are speed and claimed accuracy, not new modes.

  • Runs on the Revo Metro software that owners report crashing at high frame counts in version 5.8.5.
  • Launched December 2025, so there are fewer independent tests than for the MetroX.
  • The $1,049 Advanced Edition adds only magnetic marker blocks.
