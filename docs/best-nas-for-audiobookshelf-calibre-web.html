What each app needs

  • Audiobookshelf (ghcr.io/advplyr/audiobookshelf, v2.37.2 on 2026-10-23): volumes /config, /metadata, /audiobooks, /podcasts; the docs say /config must be on the same machine, never a network share, or the SQLite database can corrupt; it ignores PUID/PGID (use the compose user: line); multi-user with per-user progress, podcasts, and "basic ebook support" (EPUB, PDF, CBR/CBZ reader with send-to-device). No published RAM or CPU minimum; transcoding, M4B merging and metadata embedding are the heavy parts. Synology's Container Manager and Portainer can cache old images on update ("Cannot find module '/index.js'"), fixed by Reset or Recreate.
  • Calibre-Web (lscr.io/linuxserver/calibre-web, amd64 and arm64): port 8083, /config and /books, PUID/PGID supported, OPDS feed at /opds for KOReader-type apps, Kobo sync ("limited testing", no PDFs, put it behind SSL), one-click send to an e-reader. Ebook conversion needs the universal-calibre Docker mod, which is x86-64 only, so a Pi serves but does not convert. Calibre-Web Automated adds an ingest folder and auto-conversion (about 2 GB image).
  • Do you need both? Audiobookshelf alone covers a family that reads EPUBs in its web reader or sends them to a Kindle; add Calibre-Web for Kobo sync and OPDS apps. Keep the two libraries in separate folders.

Phones and remote access

Android: the official Audiobookshelf app is on Google Play, free, still marked beta, with offline listening "in beta". iPhone: no App Store listing; the official app is TestFlight-only and full, so the choices are ShelfPlayer ($5.99 one-time, iOS 26, repo archived July 2026 and under new ownership), Plappa and SoundLeaf (free with paid offline downloads), AudioBooth (free) and Absorb (free, open source, both platforms); each lists CarPlay, none independently tested. Outside the house, run Tailscale (a Compose project on UGOS; a manual SPK on Synology) and point the app at the tailnet address, or put the server behind a reverse proxy; Cloudflare Tunnel users report WebSocket disconnects. Whether UGREENlink's relay reaches the Audiobookshelf app is not documented.

Sizing

Kobo puts audiobooks at about 28 MB an hour (64 kbps); 128 kbps is about 58 MB an hour, so a 10-hour book is 0.3–0.6 GB and 500 books roughly 150–300 GB. EPUBs are negligible. One 2 TB drive holds the library many times over, which is why the NAS is bought for its bays and backups, not for this workload.
