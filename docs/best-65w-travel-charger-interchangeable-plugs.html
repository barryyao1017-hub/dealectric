The plugs you will meet

  • UK, Ireland, Malta, Cyprus: Type G (BS 1363), 230 V 50 Hz, three rectangular pins; not compatible with continental sockets.
  • Continental Europe: Type C (two round pins) and Type F (Schuko), 230 V 50 Hz; a Type C plug fits Type F sockets. Switzerland uses Type J, which accepts Type C plugs; Italy has Types C, F and L, and guides disagree on whether Type C fits every Type L socket.
  • "100–240 V": the charger takes any mains voltage, so only the plug shape changes; UGREEN's input rating is 100–240 V, 50/60 Hz.

Heads versus adapters

A charger with interchangeable heads carries its own 230 V electronics and swaps only the pins; a plug adapter puts a US charger into a foreign socket and adds a second loose part. The UGREEN, D-Link, Xtorm and PlugBug models are chargers with heads. No AU head comes with the UGREEN; Twelve South and Xtorm include one.
