# Alternative rules (Barry, 2026-11-26, DLC-358; all brands since 2026-11-27)

A listed product gets ONE researched alternative when it is **sold out**, or a **pre-order that ships more than 14 days
out** (or whose ship date is unknown or has passed). It shows as one added line under the product on every page:

> Checked Nov 26: ships Jan 11. Close match that ships now: BLUETTI Elite 100 V2 + 200 W, same 1 kWh and 1,800 W output, $679 → Buy

The original's own buy link is never changed: it always opens the original.

## Which candidate wins (in this order)

1. **Best substitute.** It must serve the same use: similar capacity, output and battery type (or the category's
   equivalent: screen size and resolution, storage bays, channels, wattage, ports); kit contents if the original is a
   kit (panels included if the original had them, similar total panel wattage); compatibility where it matters (an
   expansion battery must fit the same station; a panel must suit the same inputs); 120/240 V if the original has it.
   On a budget page it must also fit the page's budget.
2. **Ships now beats a pre-order.** A pre-order only qualifies if it ships sooner than the original.
3. **Lower price beats higher**, among substitutes that are equally suitable and equally good. Price must stay within
   **±25%** of the original's price.
4. **Same brand beats another brand.**
5. **Earns beats doesn't earn.** We earn on our affiliate brands (records with program cj/awin/rakuten) and on Amazon
   with our tag (any Amazon listing). A plain non-earning link is allowed only when the research shows the best
   substitute isn't sold through any of those.

If nothing qualifies, no alternative is added, and the verdict says why.

## Proof behind each choice

- Candidates: our own records plus a search of other stores and Amazon in the same size class (including the same
  product on Amazon, which wins every rule when it ships sooner).
- Specs: a short table comparing each candidate to the original, from the maker's page or manual.
- Price and stock: read the same day (the upkeep re-reads the winner live before using it).
- Reviews: at least one independent reviewer or owner source for the winner.
- Reasoning: one paragraph on why the winner beats the runner-up.
- Code check: our code on the winner must have passed its cart test (the daily sweep tests every published code); the
  line shows a code only when it passed on that exact product.
- Where it goes: growth/stock/<date>/research/<slug>.md, the week's CHANGES.md, the daily report and the commit message.
